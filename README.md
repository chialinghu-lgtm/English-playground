# 英語課堂遊戲：整理版

## 入口

- `index.html`：遊戲大廳，依全部、一人、雙人、多人／分組篩選。
- `teacher.html`：獨立教師後台，集中八款遊戲原有的題庫與設定。
- `games/`：清爽遊戲頁，保留作答、開始、下一題等遊戲操作。

## 本次調整

- 移除棒球單字接力挑戰賽，保留八款遊戲。
- 打地鼠、拉霸機屬於一人遊戲。
- 蛇梯棋支援 1～4 人，列入所有適用分類。
- 拔河、城堡與選擇題搶答可雙人或多人分隊進行。
- Kick it Out 支援 2～4 人；Tap & Guess 屬於多人／全班輪流遊戲。
- 分類數量由遊戲資料計算，同一遊戲可列入多個分類，因此分類數量合計可能超過八款。
- 浮動工具列改成占用獨立一列，避免遮住遊戲與設定。
- 教材與遊戲參數可在教師後台按「儲存設定」，再按「儲存並開啟遊戲」。

## 設定與資料

設定儲存在目前網站、目前裝置的瀏覽器中。不同裝置、瀏覽器或網址不會自動同步，清除網站資料也會清除設定。學生掃描 QR Code 會開啟同款遊戲，並使用學生裝置已存設定或內建題庫；不會自動取得老師自訂的教材。此版本未新增雲端資料庫或帳號權限，教師後台是獨立的設定頁，並非受登入保護的管理系統。

## 發布到 GitHub Pages

1. 將本資料夾內的 `index.html`、`teacher.html`、`games`、`js`、`css`、`README.md` 上傳到原本儲存庫根目錄。
2. 在原本儲存庫另行移除舊的 `games/baseball.html` 及其他不再使用的棒球檔案。單純上傳新版不會刪除原有檔案。
3. 等候 GitHub Pages 更新，再檢查大廳與教師後台。

也可將完整內容放入原網站的新子資料夾，例如 `v2/`，得到獨立新版網址，原頁面會繼續保留。新子資料夾下的設定與原始遊戲仍以各自的儲存鍵管理。

請以網站網址使用，確保後台與遊戲能可靠共用瀏覽器儲存空間；直接雙擊本機檔案時，各瀏覽器對儲存資料與內嵌頁面的支援可能不同。

## 驗證範圍

已檢查 HTML 內 JavaScript 語法、共用設定程式語法與本機資源路徑。另以模擬頁面環境測試四種人數篩選、八款遊戲的設定儲存／重新載入、自訂題庫還原與無效單字清單攔截。這些測試未取代實際瀏覽器遊玩：自動化瀏覽器未能連接本機預覽，因此尚未完成實際畫面與觸控操作驗證。正式使用前請在 Chrome 或 Edge 開啟，確認題庫儲存、八款遊戲啟動及投影排版。
